# GitHub User Activity
GitHub API to fetch user activity and display it in the terminal.  
[github-user-activity](https://roadmap.sh/projects/github-user-activity) challenge from [roadmap.sh](https://roadmap.sh/).
## Local setup
```bash
git clone git@github.com:Kotoninja/github-user-activity.git
cd github-user-activity
```
```
go build -o github-activity
./github-activity kotoninja
```
for more information
```
./github-activity --help
```
